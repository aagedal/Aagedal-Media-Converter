## OpenCode blocker

The additional read-only command:

```sh
/usr/bin/codesign --verify --verbose=2 /opt/homebrew/bin/opencode
```

reported:

```text
/opt/homebrew/bin/opencode: invalid signature (code or signature have been modified)
In architecture: arm64
```

This establishes that the installed binary fails signature verification. The
relationship between that result and SIGKILL has not been proven from system
logs. No reinstall, quarantine removal, or ad-hoc signing was attempted. A
working OpenCode installation is required before actual OpenCode workflows can
be validated.
