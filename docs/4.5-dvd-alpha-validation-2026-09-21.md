# 4.5 DVD subtitle contrast state — 2026-09-21

## Scope

The VOBSUB decoder previously applied contrast only to colors already selected
and reset alpha to opaque on every subsequent palette command. An alpha command
before a color command therefore lost transparency, as did a later palette
selection. This could change the bitmap passed to OCR.

The decoder now retains four independent alpha values and applies them when
selecting colors. Existing premultiplied pixel output remains unchanged.

Two generated regressions compare all pixels for equivalent color/alpha commands
in opposite orders and check partial/zero opacity plus changed RGB values after
a later palette command. They also preserve the expected subtitle timestamps.

## Limits

This is a generated bitmap regression, not real-disc recognition or manual UI
validation. The parser still emits one bitmap per SPU; this change does not add
time-varying palette animation. Missing palettes, broader real-disc inputs,
long-track memory use, OS-level grants, and signed Release validation remain open.
No dependencies or bundled binaries changed.
