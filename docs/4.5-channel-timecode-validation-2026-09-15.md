# 4.5 channel and timecode validation — 2026-09-15

## Scope

The packaged MCP Stream Copy workflow now uses a generated MOV with 5.1 AAC
audio and a `01:02:03:04` timecode track. `inspect_media` reports six audio
channels and the source timecode. The completed output decodes with the same
5.1 layout.

Agent schema v1 advertises no timecode override. An absent execution snapshot
means output timecode is disabled, even for Stream Copy. The live output check
confirms the track is removed, and the accepted-settings inspector now shows
`Timecode: Disabled` and `Date tag: No` for agent work. The local agent guide
states this policy before a user submits work.

A separate live first-party shared-job run captures preserve-source timecode in
its immutable execution snapshot. Its Stream Copy output keeps both the MOV
timecode track and the 5.1 channel layout. This verifies that manual or Shortcut
handoff can preserve the configured setting through the shared executor.
