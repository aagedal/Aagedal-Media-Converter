## UI harness corrections

The first fresh UI run launched the test app without a main window because its
bundle identifier shared persisted window-restoration state with an installed
copy. Every flow that depended on the main window consequently failed at its first
accessibility lookup. `launchApp` now passes `-ApplePersistenceIgnoreState YES`,
making each test launch independent of saved window state.

After that correction, 20 tests passed and the bilingual all-Settings audit was
terminated at the command's two-minute default. The audit passed independently in
132 seconds with a five-minute allowance. The test now declares that allowance;
the final strict-timeout run passed all 21 tests.
