# 4.5 agent cancellation during subtitle mux — 2026-09-20

## Scope

`SubtitleAgentCoexistenceTests/testAgentCancellationWhileBothProcessesRunPreservesSubtitlePublication`
covers the reverse direction of the simultaneous subtitle-cancellation regression.
It generates a two-second H.264 fixture, attaches an SRT to an existing output
through `ConversionManager`, and submits a Stream Copy agent job through
`ApplicationJobService` and the live FFmpeg adapter. Test runners pace real bundled
FFmpeg inputs and wait for progress from both subprocesses before cancellation.

The test requests cancellation through the shared service and verifies:

- The agent subprocess drains and receives cancellation; the job reaches cancelled
  with no published output URLs.
- The subtitle subprocess remains active after agent cancellation, then completes
  without receiving cancellation and publishes one subtitle stream at the expected
  duration.
- The source and SRT bytes remain unchanged, the legacy output is replaced, and
  the fixture directory contains only the source, SRT, and completed legacy output.
- After subtitle publication, the agent record still reports cancelled with no
  published output URLs.

No production changes were needed.
