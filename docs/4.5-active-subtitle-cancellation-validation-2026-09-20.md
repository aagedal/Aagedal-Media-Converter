# 4.5 active subtitle cancellation validation — 2026-09-20

## Scope

`SubtitleAgentCoexistenceTests/testActiveSubtitleMuxCancellationPreservesConcurrentAgentExport`
adds a real running-process case to the existing subtitle publication tests.
The production attached-subtitle entry point launches bundled FFmpeg against a
generated H.264 clip and an SRT file. A test-only runner adds input read throttling
and a progress pipe; it signals readiness only after FFmpeg reports
`progress=continue`. A 45-second subprocess timeout bounds failure cleanup.

The shared agent service then performs a real Stream Copy export using the same
execution gate as the conversion manager. After the agent reaches success, the
test asserts that the subtitle subprocess is still running, cancels subtitle
embedding through the manager, and awaits its completion. It verifies:

- the subprocess runner receives cancellation and drains;
- the legacy output remains byte-identical to its original;
- the agent output retains its bytes, expected duration, and no subtitle stream;
- the source and SRT retain their bytes;
- the agent record remains succeeded with unchanged output URLs; and
- no `.subtitle-embed-*` staging files remain.

No production code changes were needed. The other two cases continue to cover
successful late publication and cancellation after mux completion while the
agent owns the execution gate.

## Limits

The mux and agent export genuinely overlap, but cancellation occurs after the
agent succeeds. This does not establish cancellation while both media processes
are active. The fixture is generated local media with manually attached SRT;
Whisper/Parakeet inference, bitmap OCR, remote upload, real external-drive grants,
and user-driven preview remain separate acceptance work.
