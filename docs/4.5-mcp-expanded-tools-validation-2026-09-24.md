# 4.5 MCP tool expansion — 2026-09-24

The app now offers four additional local MCP tools:

- `list_media` browses already approved source folders and their immediate contents, with filters and pages of up to 100 entries. It skips hidden files and symlinks, and does not create grants.
- `get_plan` retrieves a plan by ID until it expires.
- `wait_for_job` waits up to 30 seconds for a state transition or terminal result. It accepts durable and currently visible manual queue IDs.
- `get_app_status` reports the running app and IPC versions and queue counts.
