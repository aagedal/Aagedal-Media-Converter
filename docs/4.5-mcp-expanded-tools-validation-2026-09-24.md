# 4.5 MCP tool expansion — 2026-09-24

The app now offers four additional local MCP tools:

- `list_media` browses already approved source folders and their immediate contents, with filters and pages of up to 100 entries. It skips hidden files and symlinks, and does not create grants.
- `get_plan` retrieves a plan by ID until it expires.
- `wait_for_job` waits up to 30 seconds for a state transition or terminal result. It accepts durable and currently visible manual queue IDs.
- `get_app_status` reports the running app and IPC versions and queue counts.

## Concurrent job waiting

The bundled helper now implements `wait_for_job` with short `get_job` polls.
The app's CFMessagePort callback handles one request at a time, so this lets
another helper process call `get_app_status` or cancel work while a client waits
for a job. The packaged Debug helper test starts a four-second wait on a manual
row and verifies that a second helper receives app status before the wait ends.
The waiting call returns the expected timeout flags. See the
[packaged helper continuation](4.5-mcp-job-list-validation-2026-09-24.md).
All seven process-level helper tests pass, and an unsigned Release build with
the polling change succeeds. Build log:
`/private/tmp/amc-45-mcp-poll-release-build.log`.
