# 4.5 anonymous usage indicator deferral — 2026-09-25

The anonymous usage indicator is out of scope for 4.5. The app no longer shows
its first-launch choice or General Settings control. `reportOnOpen` returns
before reserving a send attempt or creating a network task, including when a
previous build saved consent and a valid endpoint is supplied. The underlying
client and privacy design remain in the repository for a future release.

Validation:

- All four `AnonymousUsageIndicatorTests` passed, including a stored-consent,
  configured-endpoint regression. Log: `/private/tmp/amc-45-usage-deferred-tests.log`.
- The unsigned Release build passed. Log:
  `/private/tmp/amc-45-usage-deferred-release.log`.
- The built Release app's Info.plist has no `AnonymousUsageEndpoint`.
- A source search found no production call to `AnonymousUsageIndicator.shared`
  outside the dormant implementation, and `git diff --check` passed.

This is a 4.5 scope decision, not a claim that the retained reporting design is
ready to enable in a later release.
