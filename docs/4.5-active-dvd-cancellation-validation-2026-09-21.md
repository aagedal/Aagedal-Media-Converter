# 4.5 active DVD extraction cancellation — 2026-09-21

## Scope

Two new `OCRAgentCoexistenceTests` exercise cancellation while DVD subtitle
extraction and an agent export run through bundled FFmpeg. The generated DVD
fixture is shared with the parser/extraction tests and includes 4 KiB padding to
exercise fragmented subtitle packets. Three packets start at 0, 0.2, and 0.4 seconds. It is muxed alongside a two-second video
into MKV, then passed through the production VOB extraction and palette path.
A forwarding test runner paces demuxing and observes actual FFmpeg progress.
For DVD it also maps source video to a null output so the same subprocess stays
active at the requested read rate; subtitle-only pacing finished too quickly in
the initial runs. A nonzero 0.001-second initial burst is also required for
pacing this generated source with `-copyts`; the explicit zero-burst setting
completed immediately even with the discarded video output. A direct bundled
FFmpeg experiment verified the final pacing setup. The production DVD extraction
arguments are preserved.
Both subprocesses must still be running, with recognition not started, when the
test requests cancellation.

- Cancelling OCR must drain its extraction subprocess without starting recognition,
  publishing an SRT, or cancelling the agent. The agent must finish with a
  two-second output.
- Cancelling the agent must leave DVD extraction running to completion and allow
  controlled recognition to publish `source.ocr.srt` with the exact
  0.512–1.536, 0.712–1.736, and 0.912–1.936-second display intervals.
- Both cases check subprocess cancellation ownership, deletion of the extraction
  scratch directory, unchanged source and existing SRT bytes, exact destination
  contents, and stable terminal agent records.

The existing PGS tests use the renamed bitmap-subtitle forwarding runner and the
same fixture-directory cleanup. No production code, dependency, or binary changed.

accuracy, missing palettes, long tracks/timestamp wrapping, and UI integration
remain open. These tests do not establish OS-level grant behavior, full-suite
