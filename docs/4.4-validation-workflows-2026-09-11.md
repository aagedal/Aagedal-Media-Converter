# 4.4 workflow and attribution continuation — 2026-09-11

Baseline: `c151193`; implementation commits through `9e5b3b0`. Development version remains **4.4.0 (576)**. This is
stabilization work, not a frozen or signed distribution candidate.
Host: Apple Silicon, macOS 27.0 (26A428), Xcode 26.6 (17F113).

## Changes

- [Shortcuts review](4.4-shortcuts-review.md): retain requests until a receiver
  claims them and prevent multiple windows from handling one submission. A shared
  FIFO retains each file-bearing request’s turn across metadata loading and
  conversion, preventing competing handoffs from changing its settings.
- [Upgrade review](4.4-upgrade-review.md): preserve unreadable upload profiles
  when Settings opens; preserve malformed bookmark stores when saving access;
  resolve valid bookmarks despite malformed sibling entries.
- [Dependency review](4.4-dependency-provenance-review.md): correct FFmpeg's
  GPL version and AVM's top-level license from local artifact/source evidence,
  preserve exact evidence snapshots, and keep incomplete source/dependency review
  explicitly blocking in the publishing gate. All 29 selected MPVKit binary
  archives match the pinned checksums; rclone’s 142 embedded module records are
  preserved for source recovery.

No bundled executable, appcast, public release or user credential was changed.
