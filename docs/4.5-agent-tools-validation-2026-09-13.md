# 4.5 agent tools validation — 2026-09-13

## Scope

- Continued the local-agent workflow on top of the persisted shared job service
  and concrete FFmpeg executor.
- Added typed, Codable implementations for media inspection, preset discovery,
  conversion planning and submission, job lookup, and cancellation.
- Required a persisted user-approved read grant for media inspection and held
  its security-scoped lease for the complete probe.
- Returned structured video, audio, and subtitle stream details, timecodes, and
  exact rational frame-rate and aspect-ratio values without exposing raw probe
  output.
- Advertised only the six initial stable preset IDs and captured their resolved
  immutable settings. Per-file overrides remain unadvertised until the shared
  request model can represent them faithfully.
- Routed plan, submit, lookup, and cancel through the same application job
  service used by execution, with explicit local-agent origin and stable,
  path-safe failure payloads.

## Results

- Focused application job contract suite: **40 passed**, no failures or skips.
- Full unit target: **911 passed**, no failures or skips.
- The app and test targets compile under Swift 6 strict concurrency.
- `git diff --check` passes.

Xcode reported four QoS priority-inversion runtime warnings in the existing
general test target. They did not fail tests and are not emitted by the focused
agent workflow tests, but should be triaged during release validation.

Coverage verifies Codable round trips, exact stream mapping, security-scoped
lease lifetime, denied access, stable error conversion, supported preset
discovery, immutable settings capture, local-agent request ownership, shared
plan/submit/get/cancel behavior, and cancellation publication.

## Boundaries still open

- Build and sign the bundled MCP helper, select app/helper IPC, validate app
  launch and reconnect behavior, and test two selected local MCP clients.
- Route the visible manual queue and App Intent conversions through the shared
  service, then expose origin and job identity in the queue.
- Decide and implement the initial per-file override matrix; the current agent
  descriptors intentionally advertise none.
- Add opt-in settings, setup and connection diagnostics, permission recovery,
  queue origin labels, and disable-policy UX.
- Run representative generated-media, playback, cancellation-stage,
  restart/reconnect, sandbox-revocation, UI-regression, and signed Release
  acceptance matrices.

This is not yet a beta candidate. The internal workflow is now implemented end
to end through execution, but users and MCP clients cannot reach it until the
transport, shared visible queue adoption, and setup/diagnostic experience are
complete.
