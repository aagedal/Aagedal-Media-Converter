# 4.4 folder-access continuation — 2026-09-11

Bounded follow-up to [the saved-state upgrade review](4.4-upgrade-review.md).
Fixtures use temporary folders, isolated UserDefaults suites, and injected
bookmark operations. They do not use the user's preferences or stored grants.

## Fix

Output cleanup failed for a saved directory symlink even though output-folder
selection and Finder reveal accept it. Foundation rejected enumeration of the
unresolved link. Cleanup now enumerates its resolved target while keeping the
selected folder's security scope, preference, and child paths. The regression
verifies old visible regular files are removed and recent files, hidden files,
nested files, and the selected link remain.

An additional regression simulates an unavailable output folder, verifies that
cleanup preserves the saved location and bookmark without creating the missing
folder, then restores it and creates new cleanup/bookmark manager instances.
The new instances reuse the saved grant and resume cleanup with balanced access.
This is service-recreation coverage, not a process-restart or real-volume test.

## Existing behavior reviewed

- Watch-folder selection commits a writable grant before changing its path.
  Failed selection or renewal retains the previous path and grant.
- Legacy watch cleanup requires renewed selection while ordinary monitoring
  remains available; granting access resumes cleanup.
- Unavailable watch folders retry, deduplicate errors, and reset file stability
  before importing after recovery. Metadata failures preserve affected files.
- Output cleanup reports enumeration, metadata, and removal failures; unknown-age
  files are retained. Disabled cleanup does not acquire a scope.
- Bookmark resolution preserves unsupported stores and malformed siblings,
  retains permission modes during stale renewal, and balances overlapping access.
