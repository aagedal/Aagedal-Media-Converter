# 4.5 native bookmark validation — 2026-09-19

## Scope

The shared access authorizer now accepts an explicit bookmark manager. Its live
configuration still uses the shared manager and the same grant/lease behavior;
tests can use isolated persisted defaults with native macOS bookmark creation,
resolution, and security-scope acquisition instead of unrestricted access.

A live shared-job regression verifies:

- An accessible file without stored approval fails planning with source access denied.
- A read-only destination bookmark fails planning with destination access denied.
- An approved source folder authorizes its child media file, and upgrading the
  destination to writable permits planning.
- Recreating the service and bookmark manager restores the saved plan and grants.
- Removing either source or destination approval rejects submission without
  creating a job or output. Renewing approval preserves the original plan.
- After renewal, the plan completes through the live bundled FFmpeg Stream Copy
  adapter at its accepted output path. The output fully decodes with `-xerror`,
  and an idempotent retry returns the same job.

A second native-bookmark regression checks read and write containment while an
approved borrower holds an active scope. Both a sibling with the same path prefix
and a symlink from the approved folder to that sibling remain unauthorized.

The initial sandboxed build could not write compiler/package caches. The approved
rerun used the existing caches. Reading the final test summary also required
access to Xcode's report cache.

These tests use real macOS bookmark APIs against temporary local files. Grant
removal simulates revoking the app's persisted approval, not OS-level revocation.
The tests recreate service objects in-process, not a full app relaunch. They do
not establish interactive folder-picker behavior, external-drive loss/recovery,
App Sandbox enforcement (the current app target has it disabled), named-client
workflows, in-app playback, or signed Release packaging. Those gates remain open.
