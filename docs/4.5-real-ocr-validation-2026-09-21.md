# 4.5 real OCR and all-frame failure — 2026-09-21

## Changes

`TesseractService` previously tolerated individual recognition failures until five
consecutive failures. A shorter track could fail every frame and still publish an
empty SRT as successful output. It now counts successful recognition calls and
returns the existing `ocrFailed` error with the last diagnostic if none succeeded.
The guard runs before staging/publication; successful recognition returning no
text still follows the existing behavior. Individual failed frames in an otherwise
successful run and the five-failure threshold retain their existing semantics.

Two additional `OCRAgentCoexistenceTests` cover:

- A readable generated PGS bitmap, muxed into an H.264 MKV and extracted through
  bundled FFmpeg. After cancelling a running agent export, the production parser's
  PNG goes through bundled Tesseract and its bundled English model. The resulting
  collision-safe `source.ocr.srt` contains exactly `Media subtitle` at 0–1 seconds.
- A controlled recognition failure on the sole extracted frame returns `ocrFailed`
  and publishes no SRT while the overlapping real agent export succeeds.

Both checks preserve source/existing subtitle bytes, verify exact directory
contents and scratch cleanup, and check stable agent terminal results. The real
recognition test gates immediately before invoking Tesseract so the overlap and
cancellation are deterministic. It does not cancel during Tesseract execution.

## Apple Vision finding and limits

An initial version used real Apple Vision. Its diagnostic log reports
`Apple Vision exceeded the 10-second per-frame limit` on the generated subtitle.
The old service then published an empty SRT, exposing the production bug above.
That run passed the existing 11 tests and failed the real-recognition assertion.
The final real-recognition regression uses bundled Tesseract; the controlled
failure regression preserves coverage for the discovered service bug.

- Initial result: `/private/tmp/amc-4.5-real-vision-approved.xcresult`
- Exported diagnostics: `/private/tmp/amc-vision-diagnostics`

Apple Vision timeout diagnosis remains open. This increment does not establish
recognizer-internal cancellation, real-world multilingual accuracy, VOBSUB,
UI integration, OS-level grant behavior, or signed Release packaging. No bundled
binary, language model, or dependency changed.
