# 4.7 SwiftMediaMetadata 3.1.1 update — 2026-10-31

The app now pins the published SwiftMediaMetadata 3.1.1 release at revision
`9cb98a4068b76cf6edf5766bb6e0f6d16cfa02d5`. The release reports ProRes 4444 and
4444 XQ streams as `yuva444p12le` only when they carry alpha (sample-entry depth
32, or the frame header's alpha flag), and `yuv444p12le` otherwise. Before, every
4444 stream was reported with alpha. The app's AVFoundation depth check
(`correctingProRes4444Alpha`) stays in place as a fallback.

## Tests

The app's unit tests pass against the package resolved from GitHub. The 3.1.1
`swift-exif` CLI reads a ProRes 4444 file encoded without alpha as
`yuv444p12le` and one encoded with alpha as `yuva444p12le` (both made with
`prores_ks -profile:v 4`).
