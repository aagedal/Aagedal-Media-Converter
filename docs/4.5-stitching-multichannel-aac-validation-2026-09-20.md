# 4.5 multichannel AAC stitching validation — 2026-09-20

## Scope

Four live regressions extend the generated AAC stitching matrix to stereo and
5.1 audio, each with stitch marker export enabled and disabled. They exercise
`ConversionManager.convertGroup`, bundled FFmpeg, and a waiting shared-service
agent conversion through the same execution gate.

Each source contains two seconds of all-intra H.264 video and 48 kHz AAC audio;
the merge retains 0.5–1.5 seconds from each source. Each channel has a distinct
tone, and the second clip changes every tone. The 5.1 LFE tones are 80 and 120 Hz.
AAC encoding uses 96 kbit/s per channel. Decoded interleaved PCM is separated
into channels before checking tone identity and continuity.

Assertions cover:

- Both manual rows finish with the same output; the waiting agent begins only
  after merge publication and completes with its own output.
- Both outputs decode without FFmpeg errors and retain 48 video frames, the
  expected audio channel count, and a 48 kHz sample rate.
- Merged audio contains 96,000–100,096 sample frames, allowing whole-packet
  rounding at the cuts without claiming sample-exact trimming.
- Every channel contains the expected tone for each clip. Every tested 10 ms
  window around the join has RMS amplitude above 1,000 on the signed 16-bit
  scale, including the LFE channel.
- Marker-enabled output contains both cut chapters and EDL labels; the second
  chapter starts within two AAC packets of one second, and the final chapter
  ends within one millisecond of measured output duration.

## Limits

This validates matching-format, generated stereo and 5.1 AAC joins. It does not
establish arbitrary layouts, differing encoder delays, mixed formats, long-GOP
joins, perceptual seamlessness, or real camera-card/MXF/long-recording behavior.
Editor-driven export and OS-level grant revocation remain open.

Only regression coverage and documentation changed. No production code,
dependencies, or bundled binaries changed. A full unit-suite run, Release
package validation, signing, and notarization were not performed in this
continuation.
