# 4.5 card grouping and anonymous usage indicator — 2026-09-22

## Changes

Camera-card import now offers an opt-in recording-date review. The user marks
continuation files explicitly because the scanner has no trusted span identity.
The review shows dates in one fixed local timezone, offers a single group or day
groups with optional gaps longer than two hours, and partitions incompatible
formats. Unknown or incompatible multi-file recordings block the reviewed import.
Placeholder creation is preflighted for every source before any group is added.

The anonymous usage count now asks on first open, has a General Settings off
switch, stores a random installation secret in the device-only Keychain, rotates
an HMAC token by ISO week, and limits HTTPS attempts to once per rolling 24 hours
when the app opens. It disables cookies and redirects. No endpoint is configured,
so consent currently causes no network request. The client and server
requirements are documented in [the privacy note](ANONYMOUS-USAGE-PRIVACY.md).

## Remaining

Physical-card, MXF, spanned-recording, import/output playback, and bilingual UI
checks remain. Automatic continuation inference requires trustworthy
format-specific span identifiers and real-card fixtures.

Before enabling usage reporting, supply an HTTPS endpoint, implement the
server-side no-IP-retention controls and public privacy policy, and choose the
published metric. Weekly unlinkable tokens cannot deduplicate an installation
across an ISO-week boundary for an exact rolling seven-day count.
Developer ID signing, notarization, clean installation/update, and the other
release acceptance gates remain open.
