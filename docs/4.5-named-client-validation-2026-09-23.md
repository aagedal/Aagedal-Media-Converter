invoke `list_presets`, establishing named-client tool dispatch and a structured
helper error. It did not return presets or test source and destination grants.

established as an app defect. A separate app launch succeeded, and the next
Codex response identified disabled Agent Access. The installed 4.5 app may
differ from a later source checkout; the helper hash above identifies the binary
used.

For the successful CLI startup, `CODEX_HOME` was a mode-700 temporary directory
with a temporary copy of the existing Codex authentication file and an MCP
registration pointing at the installed helper. The directory was removed after
each run. `codex exec --ephemeral --approve-for-me` allowed the read-only tool
call to receive automatic approval. The intermediate attempt with
`--ignore-user-config` hid that temporary registration and reported the tool
unavailable; another attempt with approval policy `never` found the tool but
returned `MCP tool call requires approval, but approval policy is never`.
