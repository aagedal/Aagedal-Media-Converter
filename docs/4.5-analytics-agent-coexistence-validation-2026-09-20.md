# 4.5 analytics and agent coexistence validation — 2026-09-20

## Scope

The legacy group conversion path retains specialized post-actions outside the v1
agent contract. Two integration regressions now exercise a real legacy H.264
export with quality analytics while an agent job uses the shared execution gate:

- `ConversionQueueStateTests/testAgentConversionPreservesLegacyAnalyticsPostAction`
- `ConversionQueueStateTests/testAgentCancellationPreservesLegacyAnalyticsPostAction`

Both generate a 20-second H.264 source with the bundled FFmpeg, run the legacy
export, and run its actual PSNR helper. The helper's completion is held before
returning to `AnalyticsService`, providing a deterministic overlap with the
agent's real stream-copy export. The cancellation case waits for encoded frame
progress, cancels the actual agent subprocess, and drains it before allowing the
legacy metric completion to update its row.

Assertions cover the legacy row remaining done, its analytics operation retaining
ownership through agent success/cancellation, a finite PSNR result eventually
being published, and the agent's terminal state and output list surviving the
late analytics callback. Both source and legacy output bytes remain unchanged;
the successful agent output also retains its bytes and expected duration.

`ConversionManager` now accepts an `AnalyticsService` dependency, defaulting to
`.shared`, so tests can control the metric completion without changing production
post-action behavior or relying on machine-speed races. No metric output is
mocked: the PSNR results come from the bundled FFmpeg process.

## Remaining coverage

This closes deterministic integration coverage for quality-analytics completion
coexisting with agent conversion and cancellation. Live upload, Whisper/Parakeet,
OCR/subtitle embedding, and those post-actions' own cancellation while agent work
runs still need separate coexistence checks. These tests do not require network
services or transcription model downloads.
