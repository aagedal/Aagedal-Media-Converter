# 4.5 App Intent handoff validation — 2026-09-13

## Implemented scope

- Routed file-bearing H.264, HEVC, ProRes, Proxy, Audio Only, and Stream Copy
  App Intent conversions through the actor-owned application job service.
- Planned and submitted each request through one service operation, preserving
  the App Intent request UUID as both request identity and idempotency key.
- Persisted read bookmarks for every selected source and a writable bookmark for
  the selected destination before the asynchronous planner reopens them.
- Captured preset, filename, date-tag, timecode, and comment-formatting settings
  at handoff. The FFmpeg adapter consumes that snapshot without consulting later
  changes to user defaults.
- Kept older persisted schema-v1 requests compatible: missing first-party
  execution settings decode to the original agent behavior.
- Converted planning, authorization, or submission errors into visible failed
  Shortcut queue rows with path-safe diagnostics.
- Retained the established `ConversionManager` path for presets outside the
  initial contract and for “save encoded files next to original,” whose
  per-source destinations cannot be represented by the v1 batch request.

## Remaining boundary

Manual queue starts still use `ConversionManager`, so manual and shared-service
work do not yet have one serialization authority. The queue also needs a
dedicated inspector for the immutable accepted settings.

The shared contract still does not represent per-file trim, crop, audio routing,
merge state, custom output overrides, post-actions, generated waveform behavior,
or one destination per source. Those paths must either be added explicitly with
validation or remain outside the initial 4.5 contract.

Manual Shortcut checks with representative media are still required for cold
launch, multiple inputs, file permissions, visible progress, cancellation,
date/timecode/comment metadata, and each supported preset. Supported MCP clients,
Release signing/notarization, localization, keyboard/VoiceOver, and the broader
release acceptance matrix remain beta gates.
