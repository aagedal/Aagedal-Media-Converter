# 4.5 end guidance, surround output, and grouping continuation — 2026-09-21

## Changes

Free Stream Copy trimming now shows the requested end alongside the requested
start. A following-keyframe source reference and time difference appear only
when continuous completed scan coverage contains both the cut and the candidate.
The panel explicitly says this reference does not predict the exported end;
reordered video and audio packet tails prevent that inference. Missing neighbors
remain unavailable rather than treating the source endpoint as a keyframe.
English and Norwegian strings are included.

The camera-card grouping foundation now proposes contiguous compatibility groups
after date/gap grouping. It evaluates whole logical recordings and whole candidate
groups, preserves every span segment and input ordering, and isolates unknown or
internally incompatible recordings for review. Retaining one group still reports
its compatibility. This does not activate automatic import splitting: the importer
still needs reliable span resolution, a metadata/compatibility adapter, and a
user-reviewed proposal UI.

A new live shared-service regression generates distinct chirps in all six 5.1
channels, trims 0.75–2.25 seconds, and exports WAV, FLAC, and ProRes. Each output
must publish to its planned URL, preserve six 48 kHz channels and 1.5-second
duration, and reproduce all 72,000 selected 24-bit samples per channel byte for
byte against an independently filter-trimmed reference. This catches channel
swaps, silence, unwanted downmixing, and sample offsets that metadata-only checks
would miss.
