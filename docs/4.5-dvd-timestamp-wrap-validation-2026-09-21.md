# 4.5 DVD subtitle timestamp wrapping — 2026-09-21

## Scope

The DVD program-stream parser previously converted each raw 33-bit PES timestamp
directly to milliseconds. Crossing the clock boundary would therefore send
subtitle timing backward by approximately 26.5 hours. The parser now accumulates
the nearest signed timestamp difference before converting to milliseconds,
preserving the initial timestamp and display-command offsets.

Three generated parser regressions cover a forward wrap, repeated/small backward
timestamps, and reordered timestamps straddling the wrap. Each subtitle is split
between a timestamped PES packet and an untimestamped continuation. Assertions
check frame counts and absolute display times; the forward-wrap case also checks
every end time. Existing extraction coverage continues to exercise bundled
FFmpeg and SRT publication.

## Limits

Nearest-difference unwrapping assumes adjacent subtitle timestamps differ by less
than half the clock period (approximately 13.3 hours). It cannot recover an epoch
before the first observed timestamp, distinguish arbitrary clock resets, or
resolve longer gaps without another timeline reference. These synthetic fixtures
do not establish real-disc accuracy, missing-palette behavior, long-track memory
use, UI integration, OS-level grants, or signed Release readiness.
