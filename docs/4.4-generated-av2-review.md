# 4.4 generated AV2 video review

Reviewed 2026-09-11. Disposition: unsupported combinations remain explicitly
rejected. Adding generated-video support to AV2 is outside the 4.4 closure scope.

`FFMPEGConverter` rejects AV2 requests containing either a waveform request or a
synthesized-video request with the existing explanation: “AV2 export does not yet
support generated video from audio-only sources”. This guard precedes the native
Swift waveform rendering branch and the ordinary FFmpeg encoding branches.
The rejection finishes through the normal failed-conversion cleanup path.

Expanded `testCoreConverterUnsupportedAV2GeneratedVideoRevokesOutputRegistration`
to exercise all three request variants independently:

- Synthesized solid-color video.
- FFmpeg waveform video.
- Native Swift waveform video.

Each variant must return the same explicit unsupported error, report failure,
leave no output file, and revoke the app-created output registration. The test
also checks that the temporary directory is empty after all three requests,
covering unexpected generated intermediates in that directory. It does not claim
an exhaustive subprocess or filesystem lifetime audit.

`git diff --check` passed. The parent release-preparation task runs the expanded
regression in its combined validation. No production behavior was changed for
this review, and no live-app generated-video run was performed.
