# 4.5 Whisper-agent coexistence — 2026-09-20

## Scope

Two regressions in `WhisperAgentCoexistenceTests`, alongside the subtitle-mux
coexistence suite, exercise the production `WhisperService` and
`ApplicationJobService` with its live FFmpeg adapter. Each generates a two-second
H.264 source and waits for actual progress from a paced bundled FFmpeg export
while transcription is outstanding at a controlled subprocess boundary.

- Cancelling Whisper delivers cancellation to its runner. The runner then writes
  a staged SRT and returns success deliberately; the service must discard that
  late result. The agent stays running and finishes with the expected duration.
- Cancelling the agent drains its subprocess without cancelling transcription.
  Whisper remains outstanding until explicitly released, then publishes its SRT.
  The agent remains cancelled with no published outputs.

Both checks preserve source bytes and a pre-existing SRT. Successful Whisper
publication uses the collision-safe `source.whisper.srt` name. Exact directory
contents verify no subtitle staging or partial conversion files remain.
No production changes were needed.

## Limits

The transcription subprocess and model availability are controlled test doubles;
no Whisper model is loaded and no inference quality, GPU behavior, or real Whisper
process termination is established. The agent export uses real bundled FFmpeg.
Fixture access is unrestricted. Real inference/OCR, UI integration, OS-level
security-scoped access, and signed packaging remain open. This increment does
not run the full unit or UI suites.
