# 4.5 long-GOP trim and audio sample-range validation — 2026-09-20

## Scope

`ApplicationJobContractTests.testLiveLongGOPTrimPreservesDecodedFramesAndAudioSampleRange`
adds a generated four-second H.264 source with a 96-frame GOP, scene-cut
keyframes disabled, B-frames, and mono 48 kHz PCM audio. The audio changes from
440 Hz to 880 Hz halfway through the source.

The shared application job service exports the non-keyframe-aligned
1.25–2.75 second selection to ProRes and audio-only WAV. Both exports must:

- Publish exactly the planned output URL.
- Have a 1.5-second duration and one mono 48 kHz audio stream.
- Decode to exactly 72,000 PCM samples matching the independently selected
  source sample range, including the tone transition 0.75 seconds into the
  output, without padding or dropped samples.

The ProRes output must also contain exactly 36 frames. Every decoded frame is
compared against the corresponding independently trimmed source frame; a small
per-frame luma tolerance accommodates lossy ProRes encoding. The WAV output
must contain no video. Reference trims decode the source from the beginning
and select exact frame/sample indices using FFmpeg filters, independently of
the application's seek argument construction.

## Validation

- `git diff --check`: passed when adding the test.
- Initial focused execution reached the new duration assertion and found missing
  WAV duration in the application inspector. `VideoMetadataService` rejects WAV
  as a video container, then `SwiftMediaMetadata.AudioMetadata` returns audio
  stream details without duration. Its WAV parser ignores `data`/`fact` chunks.
- The inspector now uses the existing bounded duration probe when the audio
  parser omits duration, matching the essential-info path. Cancellation remains
  propagated after the fallback. Exact sample and frame assertions are unchanged.
- The new regression passed in the full Debug unit run: all 1,020 unit tests
  passed with no failures or skips. Log:
  `/private/tmp/amc-4.5-continuation-final.log`; result bundle:
  `/private/tmp/amc-4.5-continuation-final.xcresult`. The combined run also included
  two UI tests that failed on a test-only checkbox value cast; they were rerun
  separately after correcting that assertion.

## Remaining limits

This deterministic fixture extends output validation beyond stream metadata and
successful decoding. It uses unrestricted test authorization and does not prove
sandbox bookmarks, interactive playback, variable-frame-rate or drop-frame
material, stream-copy keyframe trim behavior, or AAC priming behavior. Larger
real-world sources and additional audio routing modes remain release checks.
