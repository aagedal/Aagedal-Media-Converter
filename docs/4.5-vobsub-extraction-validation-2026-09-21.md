# 4.5 VOBSUB extraction continuation — 2026-09-21

## Changes

The OCR service no longer asks FFmpeg to produce an unsupported VOBSUB `.sub/.idx`
pair. It stream-copies the selected subtitle track into an MPEG-2 VOB program
stream and dumps that track's codec header separately for its RGB palette.
Both outputs remain in the existing per-run scratch directory, with the existing
subprocess timeout, cancellation ownership, and deferred cleanup.

The parser now reads PES presentation timestamps and uses the existing fragmented
SPU decoder for pixel/control data. Parser scans check task cancellation, and the
service preserves cancellation errors instead of wrapping them as parse failures.
No dependency or bundled binary changed.

The first implementation used `-f dvd`. The integration test caught the muxer
rebasing the first subtitle timestamp to 0.5 seconds despite `-copyts`. The final
path uses `-f vob -avoid_negative_ts disabled` with `-copyts`. The corresponding
DVD-specific offset behavior is visible in the primary
[FFmpeg MPEG muxer source](https://www.ffmpeg.org/doxygen/trunk/mpegenc_8c_source.html).

## Validation

A generated MKV contains two DVD subtitle tracks with distinct palettes and
start times. Extraction of subtitle index 1 must return yellow pixels and a
7.512–8.536-second display interval. The service then publishes the exact SRT
interval through a controlled recognizer, preserving both the original MKV and
an existing SRT while choosing another output name. A 4 KiB padding region in
the selected SPU exercises reassembly across multiple PES packets.

The Debug build and all 18 focused VOBSUB parser, OCR, Whisper, and subtitle-mux
coexistence tests passed. The initial sandboxed build could not access compiler
and package caches; subsequent Xcode runs used approved cache access.

## Remaining validation

Recognition in the new DVD test is controlled, not real Tesseract or Vision.
DVD-specific active-extraction cancellation while an agent export runs, scratch
cleanup assertions for that overlap, real DVD/disc sources (including missing
palette metadata), long tracks/timestamp wrapping, and app UI integration remain
open. The existing PGS cancellation and real Tesseract regressions still pass.
This is not full-suite, manual UI, or signed Release validation.
