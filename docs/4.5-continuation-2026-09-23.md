## Changes

- Exact Xcode project revisions now provide durable Swift package pins. The
  dependency manifest compares them with reviewed attribution, and release
  commands no longer require Xcode's discarded workspace lockfile. See the
  [package pin record](4.5-package-pin-validation-2026-09-23.md).
- Completed native keyframe scans can serve contained requests for the same
  source identity and video track. This avoids rereading nearby trim regions.
  The scanner still treats sync samples as candidate seek points.
- Sparse-GOP discovery now checks adjacent bounded regions when the central
  search cannot establish a preceding or following sync sample. It combines
  only completed, continuous coverage, retaining the completed central result
  if an adjacent read cannot finish.
- Recording-date camera-card import now requires a valid card name before
  opening review and checks it again before creating groups. It also saves the
  selected upload server when the review flow begins.
