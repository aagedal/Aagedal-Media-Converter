# 4.4 generated preview UI smoke review

## Coverage

Two XCTest UI flows open the actual Preview / Trim sheet from the queue context
menu using app-generated, six-second 320×180/24fps video with a sine-wave audio
track. MP4 exercises AVPlayer; Matroska exercises the existing forced-MPV path.
The tests assert the active backend reports ready, edit the visible timecode to
`00:00:01:00`, capture a frame, and wait for the screenshot-reveal control to become
enabled after publication. They play with L, require the timecode to advance,
pause with K, and require the timecode to remain stable. They close and reopen the
sheet and repeat seeking and playback, then confirm the queue item remains waiting.

The screenshot directory and format use volatile UI-test defaults pointing inside
the generated fixture directory. Existing app-owned fixture cleanup removes the
inputs and screenshots. The readiness/backend accessibility value exists only in
DEBUG UI-test sessions; production adds only a stable media identifier and an
accessible close-preview identifier/label.

## Validation

The first signed Xcode UI run passed both seek/capture/reopen flows on 2026-09-11:
MPV in 30.633 seconds and AVPlayer in 28.748 seconds. Result bundle:
`/private/tmp/aagedal-44-preview-ui-retry.xcresult`.

A second signed run added actual play/pause assertions and passed both tests:
MPV in 35.174 seconds and AVPlayer in 33.444 seconds. Result bundle:
`/private/tmp/aagedal-44-preview-ui-final.xcresult`.

The final combined run includes both preview tests plus existing conversion success,
failure-details, and cancellation smoke tests. Preview attachments now capture the
full app: capturing only the parent window cropped the larger preview sheet and
cannot establish a real viewport defect. The combined signed run passed all five tests with zero failures:
conversion failure details (16.797s), successful conversion (9.174s), MPV preview
(33.431s), AVPlayer preview (32.697s), and conversion cancellation (12.560s).
Result bundle: `/private/tmp/aagedal-44-preview-ui-combined.xcresult`.
Build/test log: `/private/tmp/aagedal-44-preview-ui-combined.log`.

## Limits

These checks exercise generated SDR media in the app-owned temporary directory.
They do not establish audible audio output, HDR rendering correctness, previewing
all input formats, external-volume security-scoped access, or playback through
sleep/wake. Screenshot-reveal readiness follows successful screenshot publication;
the UI test does not open Finder or inspect private fixture files from its runner.
Visual attachments in the result bundles support separate rendered-frame review.
