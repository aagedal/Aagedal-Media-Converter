# 4.5 live PGS extraction — 2026-09-21

## Scope

The two existing OCR-agent coexistence tests now use a real bitmap subtitle
track. A generated minimal PGS display set is muxed with two seconds of H.264
video into an MKV using bundled FFmpeg. The standalone SUP fixture is removed
before OCR starts, so the production extractor must retrieve the track from the
MKV. A forwarding subprocess runner records the extraction destination for
scratch-cleanup assertions and delegates execution unchanged to SubprocessRunner.

The production PGS parser renders the extracted display set to PNG. Recognition
remains controlled to hold work outstanding and deliberately return late success.

- Cancelling OCR rejects late recognized text while the concurrent real agent
  FFmpeg export succeeds with the expected duration.
- Cancelling the agent drains its export while OCR remains active, then publishes
  the exact one-second SRT as source.ocr.srt without overwriting source.srt.
- Both tests verify unchanged source and existing subtitle bytes, exact output
  folder contents, stable terminal agent records, and removed OCR scratch files.

## Limits

This covers generated PGS extraction from MKV, parsing, and service
cancellation/publication isolation. It does not establish VOBSUB extraction,
complex real-world PGS compatibility, recognition quality, real OCR engine
termination, overlapping extraction-process cancellation, live UI behavior,
OS-level security-scoped access, or signed Release packaging. No production
behavior or bundled binaries changed.
