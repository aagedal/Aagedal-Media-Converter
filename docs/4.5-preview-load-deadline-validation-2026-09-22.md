# 4.5 MPV preview load deadline — 2026-09-22

## Changes

An MPV preview that never publishes readiness or failure now times out after
30 seconds and enters the existing localized error/Retry flow. The deadline
starts when the controller installs the source's MPV observers, including the
wait for drawable attachment. Successful readiness cancels it. Failure,
replacement, and teardown cancel it and invalidate its observation identity.

The deadline holds the controller weakly while waiting. Timeout uses the same
teardown as a decoder error, retaining the selected audio track for Retry.
Late readiness and EOF cannot revive or advance the failed source. Existing
English/Norwegian error copy is reused; no catalog or dependency changes.

## Limits

The silent decoder is represented by controlled publishers; this does not
establish recovery from a synchronous native-library hang or blocked main actor.
The 30-second limit is a conservative initial policy, not a measured upper bound
for all camera media or external drives. Native AVPlayer loading is unchanged.
No new UI/manual playback, full-suite, conversion, OS-level grant revocation,
physical-drive, Release signing, or notarization validation is claimed.
