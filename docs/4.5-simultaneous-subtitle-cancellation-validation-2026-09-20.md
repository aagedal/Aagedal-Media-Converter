# 4.5 simultaneous subtitle cancellation validation — 2026-09-20

## Scope

`SubtitleAgentCoexistenceTests/testSubtitleCancellationWhileBothProcessesRunPreservesAgentExport`
extends the existing active-mux regression to cancel subtitle embedding while the
agent's FFmpeg process is also running. Both paths use the bundled FFmpeg and
production conversion entry points. Test-only runners pace input reads and wait
for real `progress=continue` output before asserting that both children are active.
The agent runner preserves the subprocess request's environment, working directory,
input, capture limits, termination grace period, and redaction settings.

The test cancels only the attached-SRT mux through `ConversionManager`, waits for
its subprocess to drain, and verifies that the agent subprocess and shared job
remain running. The agent then completes its Stream Copy export through the live
application executor. Assertions cover cancellation delivery to the mux, no
cancellation delivery to the agent, successful agent output with the expected
duration and no subtitle stream, unchanged source/SRT/original legacy output,
and removal of subtitle staging files.

## Validation

The initial sandboxed Xcode invocation could not write package/compiler caches.
The approved run built successfully, but the new test timed out waiting for agent
progress: its test runner observed stdout while the production command's later
`-progress pipe:2` sent the protocol to stderr. The observer now uses the existing
stderr protocol, with no replacement progress destination. The three existing
coexistence tests passed in that initial run.

The corrected focused Debug run passed all four `SubtitleAgentCoexistenceTests`,
including the simultaneous-process case (5.276 seconds). `git diff --check` passed.

## Limits

This uses generated local H.264 media and manually attached SRT. It does not cover
the reverse direction (cancelling an active agent while subtitle muxing continues),
Whisper/Parakeet inference, bitmap OCR, upload, real external-drive grants, or
user-driven playback. No production code changes are included.
