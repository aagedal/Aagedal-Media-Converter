# 4.5 inspection access-loss validation — 2026-09-15

## Scope

`inspect_media` now checks that an approved source is a regular file before
launching its probe. If the probe fails, it reads fresh filesystem attributes
and returns `source_unavailable` when the source disappeared during inspection.
A malformed source that remains available still returns
`media_inspection_failed`, and cancellation remains cancellation. This avoids
using cached URL resource values for the post-probe access-loss decision.

Three regressions cover a disappearing source, a present malformed source, and
a directory passed as a source. They use isolated temporary files and an
injected inspector; they do not simulate an actual external-drive unmount.
