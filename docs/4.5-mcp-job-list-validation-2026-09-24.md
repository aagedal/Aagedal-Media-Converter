# 4.5 MCP job listing continuation — 2026-09-24

## Change

`list_jobs` now returns paginated summaries with UUIDs, states, source filenames,
presets, and progress. It combines the current visible manual queue with the
shared service's durable job records. Manual file and group entries use their
existing queue UUIDs; `get_job` accepts those IDs while the rows remain in the
current app session. Durable shared jobs retain their existing IDs and
`cancel_job` behavior. The listing omits full source paths, and manual entries
advertise that they cannot be cancelled through MCP.

The app publishes the manual queue projection when files, groups, display order,
or the selected preset change. The bundled helper advertises `list_jobs` with
`offset` and `limit` arguments; pages contain at most 100 entries and report
`total` and `hasMore`.

## Packaged helper continuation

The focused live Stream Copy XCTest now starts the freshly built Debug helper
from the test-host app bundle, submits and completes a real FFmpeg conversion,
then publishes a manual queue row in the app's visible queue registry. Separate
stdio helper calls show both IDs through `list_jobs` with `limit: 1` pages,
including `total`, `hasMore`, terminal state, manual cancellability, and
path-free source names. `get_job` resolves the manual row's listed ID. The test
also starts a four-second `wait_for_job` in one helper process while another
helper gets app status; the status call completes without waiting for the first
call to time out. The waiting call then returns `timedOut: true` and
`changed: false`.

This test caught and helped fix a request-ID casing mismatch in the new helper
polling path. The focused test passed after the fix. Log:
`/private/tmp/amc-45-mcp-list-packaged-test.log`. It uses the test port and an
injected unrestricted file authorizer. It does not replace the remaining
installed Release app check with actual first-party folder grants and a manual
row added through the UI.
