## Limits and release gates

The Xcode 27 test invocation with `-onlyUsePackageVersionsFromResolvedFile`
removed the restored workspace `Package.resolved` during resolution, then
failed because automatic resolution was disabled. A normal build using the
cached package source completed. After builds finished, the active Xcode
environment continued to delete the file within seconds of restoration.
The release script's dependency-manifest and strict package-resolution/archive
path therefore need a durable pinning solution and a successful run before
distribution.

The Release app was built with `CODE_SIGNING_ALLOWED=NO`; this is not a signed
or notarized distribution candidate. This host reports zero valid code-signing
identities. MPV publication/integration and affected-macOS CoreAudio recovery,
physical-card and real-span checks, named-client workflows, bilingual visual
review, and clean installation/update validation remain open.
