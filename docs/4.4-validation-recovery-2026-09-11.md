## Changes

- `c173275`: [Folder-access review](4.4-folder-access-review.md) fixes output
  cleanup through a selected directory symlink. New tests also cover unavailable
  output-folder recovery through recreated service instances with saved access.
- `6d3402a`: [Download recovery](4.4-download-recovery-review.md) uses the
  current download's reported destination instead of guessing ownership from
  recent files. An unchanged pre-existing completed file is not recovered merely
  because its path matches the reported destination.
- `2dfb34b`: Download retries retain and await the cancelled attempt before
  starting a replacement. Rapid retries, forced re-downloads and cancellation
  while waiting preserve ownership. Playlist cancellation reaches the current
  child, skips later entries, and clears state even before helper startup. A
  second agent independently reviewed the task chain and found the pre-start
  state edge, which now has a deterministic regression.
- `7afc21f`: Real-app keyboard regression starts and cancels encoding, resets
  the item, retries successfully, then resets and converts again with an existing
  output. Both completion screenshots were captured; the second was visually
  inspected and shows the completed 15-second H.264 fixture and export size.
- `f864fed`: [Dependency provenance](4.4-dependency-provenance-review.md)
  retains 39 byte-verified AVM dependency/build snapshots and inventories 17
  components using 858 compiler dependency records. Missing libyuv notices and
  unpinned fetched dependency source identities remain explicit blockers.
- `d86f825`: Recovers the exact rclone source revision and all 142 dependency
  modules. Go-verified module checksums match both the binary metadata and main
  source `go.sum`. Retains 197 module notice candidates plus main-source and Go
  runtime notices. Build selection, file-level/embedded-asset review and offline
  packaging remain open; this does not close attribution.

## Remaining release gates

Automated folder recreation does not establish real sandbox renewal, process
restart, or removable-volume behavior. Download ownership fixtures do not
replace live network retry/cancellation. UI automation does not establish audible
playback, VoiceOver usability, real Shortcuts execution, recording/editor sync,
or installed 4.3 upgrade behavior. Full attribution, real-model transcription,
signed/notarized distribution, controlled update, and minimum-supported-macOS
validation remain required by [the release plan](RELEASE-4.4-PLAN.md).
