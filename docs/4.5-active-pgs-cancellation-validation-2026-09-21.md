# 4.5 active PGS extraction cancellation — 2026-09-21

## Scope

Two additional `OCRAgentCoexistenceTests` exercise cancellation while subtitle
extraction and an agent export are both running through bundled FFmpeg. The
existing generated PGS-in-MKV fixture is reused. A test-only forwarding runner
paces extraction and observes FFmpeg progress before starting the agent; both
runners must still be active, with recognition not yet started, at cancellation.

- Cancelling OCR drains its extraction subprocess without invoking recognition,
  publishing an SRT, or stopping the agent. The agent finishes with the expected
  two-second output duration.
- Cancelling the agent drains its export while extraction completes normally,
  parsing reaches recognition, and OCR publishes the exact one-second SRT as
  `source.ocr.srt` without replacing the existing `source.srt`.
- Both cases verify unchanged source/existing subtitle bytes, exact output-folder
  contents, removal of the extraction scratch directory, and stable terminal
  agent records. The extraction runner records whether cancellation reached its
  real subprocess.

Extraction may naturally finish while the cancelled agent is draining. The test
therefore requires overlap at cancellation and successful subsequent extraction,
not that extraction remains active after the agent reaches its terminal state.
The latter timing-dependent assertion failed in the initial runs and was removed;
the overlap, process-cancellation, recognition, and output assertions remain.

## Limits

Recognition remains controlled for deterministic publication/cancellation checks.
This does not establish real OCR accuracy or engine termination, VOBSUB extraction,
complex real-world PGS compatibility, live UI behavior, OS-level security-scoped
access, or signed Release packaging. No production behavior or bundled binaries
changed.
