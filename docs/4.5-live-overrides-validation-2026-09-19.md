# 4.5 live per-source override validation — 2026-09-19

## Scope

Two live regression tests expand the release output matrix for first-party
per-source settings captured by the shared job service. The existing adapter
mapping tests verify captured arguments; these tests submit plans to the live
FFmpeg adapter and inspect the resulting files with the app's metadata inspector.

- Trim/crop/mute: a generated three-second, 128×96 H.264 source with audio is
  trimmed from one to two seconds, cropped to the central half in each dimension,
  and muted. The accepted custom output name is preserved. The resulting file
  has 24 frames, a one-second duration (within one frame), 64×48 video, and no
  audio stream.
- Audio routing: a generated source with six-channel 48 kHz PCM audio is encoded
  through H.264 with captured routing. One job preserves six channels; another
  explicitly downmixes to two. Each output contains exactly one audio stream at
  48 kHz and matches its accepted output path.
- Every resulting file is fully decoded with bundled FFmpeg using `-xerror`, so
  decoding errors fail the test.

This increment adds tests and documentation. No production behavior, dependency,
bundled binary, schema, or UI changes were needed.

## Validation

- Debug build and all 90 `ApplicationJobContractTests` passed, with zero failures
  or skipped tests in the result bundle.
- `git diff --check` passed.
- Evidence: `/private/tmp/amc-4.5-live-overrides-suite.log` and

The initial sandboxed build could not write compiler/package caches; the approved
rerun used the existing caches. The first test implementation assumed a bundled
ffprobe executable and failed its lookup after conversion. The final tests use
the app's existing metadata inspector and bundled FFmpeg instead.

These generated fixtures use an unrestricted injected access authorizer. They do
not validate real security-scoped bookmarks, named MCP clients, subjective
playback, exact downmix sample amplitudes, Stream Copy cut boundaries, or signed
Release packaging. Those acceptance gates remain open.
