# 4.5 SwiftMediaMetadata 3.0.3 update — 2026-10-22

The app now pins the published SwiftMediaMetadata 3.0.3 release at revision
`74794cf1b9fd8ad0156eb695f816241eb00271c9`. The release includes MXF partition
skipping for bounded metadata reads and correct displayed dimensions for 1080
XAVC footage.

The app also retries metadata probes once after a timeout, maps the FourCC codec
names used by the library to FFmpeg encoders, and avoids forcing x264's 8-bit
4:2:0 High profile when encoding other pixel formats. Regression tests cover
these app-side changes.
