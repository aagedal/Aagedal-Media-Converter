# 4.4 attribution completion — 2026-09-12

The outstanding dependency attribution gate is resolved. The inventory covers
10 bundled tools, three pinned Swift packages, 12 offline notices and 89 retained
source archives. The strict gate passes without bypasses. Source archives remain
under ignored `build/attribution/`; preserve the source companion with release
artifacts and upload it alongside the application.

## Changes

- AVM notices cover the root project and 17 dependency groups, including 277
  file-level blocks. Eigen corresponding source includes all 368 referenced
  files; the historical libyuv license/patent/author material was recovered.
- rclone was rebuilt from its recovered source revision with the unused
  `serve s3` command removed, eliminating its linked AGPL dependency. S3 uploads
  and all six app storage backends remain available. The source companion
  contains the exact patch, Go/toolchain/module inputs and relinking directions.
  An offline rebuild reproduced the ad-hoc-signed helper byte-for-byte.
- FFmpeg 9.0.1 was rebuilt from retained source trees. All previous encoder,
  decoder, filter (including Metal), muxer, demuxer and protocol lists match.
  Its notice includes 124 source notices. The companion preserves source trees,
  exact invoked recipes and an adjusted recipe that rebuilds extracted sources.
  Compiler dependency evidence accounts for 2,074 absolute source references,
  including 28 generated source files in a separate audit archive.
- MPVKit notices cover all 29 targets with 1,399 verified notice fragments and
  84 source archives. All 16 custom mpv/FFmpeg architecture slices match the
  retained builds. The review includes framework transitive sources and runtime
  notices. uavs3d's exact source revision is unavailable (its BSD notice was
  recovered); the Rust nightly identity is a build-date inference. This does
  not claim independent reproduction of every upstream framework binary.
- OCR notices now include Leptonica and libpng. BMX/asdcplib notices include
  their embedded library, hashing, AES and other third-party material.
- About > Licenses includes AVM, rclone and MPVKit. A native selectable text view
  handles the large complete notices. All notice files are Xcode resources.
- Package attribution is bound to exact Swift package revisions. Release checks
  verify required source components and hashes. Release outputs use a separate
  directory so cleanup preserves sources. Source uploads precede replacement
  binaries; new releases remain drafts until both uploads succeed.
