# 4.5 unavailable-source validation — 2026-09-15

## Scope

An approved source can disappear between a user's folder grant and an agent
request, for example when an external drive is unmounted. Planning previously
passed a filesystem identity error to the tool boundary, which reported a
generic internal failure. Inspection passed the missing path to the media probe
and reported `media_inspection_failed`. Both operations now return the stable
`source_unavailable` code after approved access is acquired. No plan or job is
created for a missing source, and inspection does not launch the probe.

## Validation

- Focused planning and inspection regressions passed with a missing source and
  an approved read lease.
- The typed IPC dispatcher reports `source_unavailable` for both tools.
- All `ApplicationJobContractTests` passed, including the existing lease-lifetime
  inspection test with a real temporary file.
- The dedicated macOS unit-test scheme passed all 941 tests.
- `git diff --check` passed.

This covers a source unavailable at request time. A live grant on a disconnected
external drive, reconnecting it, and retrying from a named MCP client still need
packaged validation.
