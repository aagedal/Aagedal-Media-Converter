# MPV candidate archive validation — 2026-09-22

The retained CoreAudio-patched candidate passes the expanded read-only audit in
`scripts/verify-mpv-candidate.py`. Seven artifact hashes match the retained build
evidence, the framework contains exactly `arm64` and `x86_64`, and each thin static
archive contains only its named architecture. Both release ZIPs contain the same
binaries as their corresponding staged artifacts.

The verifier previously checked actual architecture only for the universal
framework. Valid hashes and archive correspondence alone could accept a mislabeled
thin archive. It now checks each thin archive with `lipo -archs` and records the
result in its JSON report. ZIP members and XCFramework binary metadata also reject
absolute, parent-traversing, ambiguous, and backslash paths before comparison.
Normal framework symlinks are preserved; the audit does not extract archives.

  --candidate /private/tmp/amc-mpv-coreaudio-20260922-d \

All 15 candidate-verifier tests passed, including wrong thin architecture,
universal binaries in thin locations, unsafe ZIP paths, and invalid XCFramework
binary locations. The real retained candidate passed the expanded audit.

This does not establish release readiness. Versioned archive publication and the
package pin, complete source/dependency provenance and notices, release-bundle
