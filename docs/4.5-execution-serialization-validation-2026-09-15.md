# 4.5 execution serialization validation — 2026-09-15

## Scope

Application-owned jobs and legacy manual/group conversion batches now share a
FIFO execution gate around their primary conversion work. An accepted service
job waits for an active legacy batch before validating queued inputs and handing
off to FFmpeg. A service job cancelled while waiting remains terminal and never
starts its executor. Legacy requests cancelled during the wait are fenced by a
cancellation generation before conversion preparation.

The first full-suite run exposed a regression in the gate wrapper: a legacy
retry during an overlapping cancellation waited for the active batch's gate,
preventing the test from finishing the drain. Admission now checks the manager's
active-batch and pending-cancellation state before waiting, while retaining the
same check inside the gated conversion method for actor re-entry. The existing
overlapping-drain regression and both new gate tests pass after that correction.

This gate covers conversion-engine ownership. Legacy post-conversion follow-ups
and their output interactions with agent jobs still need live coexistence checks.
