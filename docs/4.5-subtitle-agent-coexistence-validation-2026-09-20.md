# 4.5 subtitle publication and agent coexistence — 2026-09-20

## Scope

`SubtitleAgentCoexistenceTests` adds two deterministic integration regressions for
legacy subtitle embedding alongside the shared agent execution service:

- `testLateSubtitlePublicationPreservesCompletedAgentExport`
- `testSubtitleCancellationWhileAgentRunsPreservesBothOutputs`

Both generate a real H.264 fixture, copy it into a legacy output, and run the
bundled FFmpeg to mux an SRT subtitle into a staged file through
`ConversionManager.embedSubtitlesForAttachedFile`. A controlled subprocess wrapper
holds the successful mux completion immediately before the manager can publish
its result. The agent acquires the shared execution gate while this post-action
is outstanding and exports the original source through the live stream-copy
executor.

The success case completes the agent first, then permits the late legacy
publication. The cancellation case cancels legacy embedding while the agent owns
its execution gate, drains the held completion, and then permits the agent's real
export. Assertions inspect actual output media for the expected subtitle stream
counts and agent duration; they also compare source, subtitle, and output bytes,
verify the agent's terminal record, and reject leaked `.subtitle-embed-*` files.

No production behavior changes are required for these cases. They exercise the
existing independent attempt ownership and cancellation checks at the staged
subtitle publication boundary.

## Limits

These cover the shared subtitle mux/publication machinery through manually
attached SRT files. They do not execute Whisper/Parakeet inference, bitmap OCR,
remote uploads, or cancellation of a still-running subtitle FFmpeg process. The
controlled cancellation happens after the real mux subprocess has completed and
before publication, with the agent executor admitted but held before its media
subprocess starts. Existing service-specific cancellation tests remain relevant;
live network/model post-actions and broader end-to-end coexistence remain open.
