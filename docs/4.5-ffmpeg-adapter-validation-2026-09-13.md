# 4.5 FFmpeg adapter validation — 2026-09-13

## Scope

- Continued milestone 2 after the transport-neutral execution handoff.
- Connected the live shared job service to an app-owned adapter around the
  bundled `FFMPEGConverter`.
- Reconstructed executable settings for the initial H.264, HEVC, ProRes, Proxy,
  Audio Only, and Stream Copy subset from each accepted immutable snapshot.
- Kept later preference changes out of accepted work and rejected semantic
  combinations the existing engine cannot represent faithfully.
- Executed batch source/output pairs in plan order, aggregated per-file progress,
  stopped the batch on the first failure, and returned only accepted output URLs.
- Routed cancellation through the active adapter owner and waited for the
  existing FFmpeg cancellation fence before returning a terminal result.
- Replaced the executor's escaping progress closure with a sendable reporter
  object so the boundary remains valid under Swift 6 strict concurrency.
